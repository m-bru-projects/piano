# Standard library

These scores are loaded on demand from `library/manifest.json`. They sit beside the two built-in demos in the piece menu.

Each file was converted from a Mutopia Project LilyPond source (git commit `2144afd6f52d56c5b6995b8b589ef1268b3139f0`) by rendering MIDI with LilyPond 2.24 and translating that MIDI into MusicXML. The Mutopia header of each source records the license below. LilyPond's own engraving (slurs, fingerings, ornaments, articulations, and repeat signs) is not in the MusicXML. Repeats follow whatever the LilyPond MIDI emitted, which is usually a single pass rather than an unfolded da capo.

The music itself is public domain. The four CC BY-SA editions are share-alike editions by the maintainers named in the table; keep their attribution if you redistribute those files.

MuseScore's OpenScore / OpenWTC editions were not used: the download site blocked this environment. The music21 corpus was not copied, because its license file says individual encodings may be copyrighted and are only licensed for use with music21.
